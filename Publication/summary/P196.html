효과적인 TTPs 분석을 통한 침해대응 강화: 설계 접근법

Enhancing Incident Response Through Effective TTPs Analysis: A Design Approach

한태현 · 황상연 · 이태진(교신) 가천대 · SecuLayer IEEE Access 13, 217799–217810 (2025)SCIE 2025.12 게재 · Open Access(CC BY) DOI: 10.1109/ACCESS.2025.3645226

핵심

MITRE ATT&CK 지식과 실제 침해대응 데이터를 연결한 TTP 그래프를 metapath2vec 임베딩(기법 클러스터)과 TF-IDF 공격 패턴 행렬로 지식 맵화 → 탐지된 몇 개 기법만으로 공격자의 다음 행위를 추론하고, 후보군 + XGBoost로 공격 그룹을 식별해 탐지–대응을 잇는다

93.49%공격 그룹 식별 정확도 (ID-K-G, XGBoost 단독 87.19%)
91.73%기법 클러스터 신뢰도 (ID-K-T, Jaccard·Phi 대비 우위)
142,949검증에 쓴 실제 침해사고 인스턴스 (ID-C-T)
569MITRE ATT&CK v18.0 기법 · 사고당 평균 7개 사용
4.01ms건당 추론 시간 (XGBoost 0.93ms, EDR/AV 허용 범위)

①문제의식

  • 지능형 공격: APT는 제로데이로 시그니처·AI/ML 탐지를 우회(Stuxnet, 대만 정전) → Cyber Kill Chain·TTPs 기반 대응 부상
  • 오탐 문제: KISA 보고 — 탐지된 기법의 83%는 정상 사용자 행위와 구분 불가 → 기법 간 인과·상관 분석이 필수
  • 실환경 공백: TTPs 방어는 효과적이나 운영 환경 적용 연구 희소, 기법 간 의미 있는 관계 식별·정량화가 난제
  • 단절된 대응: 수집·포렌식·DB(MITRE·CVE·CAPEC)·정책 갱신이 독립 시스템 → 소통·효율 저하, 표준 지식으로 연결 필요

②기존 연구와 차별점

계열대표한계
TTP 분석Al-Shaer(Jaccard·Phi), Al-Sada, KISA쌍(pairwise) 상관만 포착 → 다수 기법 간 복합 의존 미반영
위협 모델링AttackG, ThreatWeaver, KillChainGraph사전 정의 규칙·기지 조합에 의존, 합성·태깅 데이터(표준 데이터셋 부재)
공격자 예측GloVe·TF-IDF 임베딩, 시퀀스 모델, DeepOPTTP만으론 그룹 식별 불가(기법 공유), 위협정보는 실제 순서로 관측 안 됨
제안실제 침해대응 메타데이터 + 임베딩(다대다 관계 학습, 규칙 정의 없음) + TF-IDF 후보군 + XGBoost 결합, 전 기법 범위

④평가 데이터 (6종 · 실사고 메타데이터)

  • 지식(ID-M): MITRE ATT&CK v18.0 — Enterprise·ICS·Mobile 그룹·캠페인·SW·전술·기법·완화책 통합, 학습 전용. 기법을 4단계(인프라 확보 → 초기 침투 → 내부 활동 → 목표 달성, 단계당 전술 2–9개)로 분류
  • 기법 상관(신뢰도): ID-T 2,862건(그룹 라벨은 73건뿐 → 검증 가능 건만), ID-K-T 학습 4,271/검증 3,132, ID-C-T 142,949건 전량 검증
  • 그룹 식별: ID-K-G 67그룹(학습 9,855/검증 4,903), ID-C-G 50그룹(학습 28,939/검증 10,172) — 145 피처 = 실행파일 바이트 4-/10-gram 유사도
  • 출처: 전문 침해대응 기업 제공 실제 사고 메타데이터(기존 연구는 보고서 기반 시뮬레이션 데이터)

③제안 방법

  • 그래프 설계: 그룹–기법, 캠페인–기법, 소프트웨어, 완화책 관계를 모두 담은 이종 TTP 그래프에 실사고 인스턴스를 연결, 기법은 4단계 공격 수행 단계로 배치
  • 연관 학습(metapath2vec): 메타패스 5종(그룹–기법·그룹–SW·캠페인–기법·캠페인–SW·기법–완화책), 경로 길이 500·20경로·윈도 3(1-depth 직접 관계만 학습, T0−G1−T2−G3−T4 같은 간접 경로는 잡음), 64차원(32–256 차이 없음). 이웃은 당기고 비이웃은 밀어내는 스킵그램 목적함수
  • 다음 행위 추론: 탐지된 n개 기법과의 유클리드 거리 합(min-max 정규화로 메타패스 간 결합)이 최소인 기법 = Tnext. 거리는 계층적 군집(ward)으로 관리 → 한 군집 = 동시 발생 가능 기법, 임계값·연결법은 도메인별 조정 가능
  • 통계 분석(TF-IDF): 문서=그룹·단어=기법 → 공격 패턴 행렬 TR(t,ta)=log(전체 그룹 수 / t 사용 그룹 수). T1105(83그룹) 0.129 ↔ T0852(2그룹) 0.8: 값이 클수록 특정 그룹 고유 기법
  • 그룹 식별: 탐지 기법 가중 합으로 상위 N 후보군 C 산출 → XGBoost(lr 0.3, depth 4)의 리프 출력을 C로 제한해 최종 판정(의사결정트리보다 우수). 예: T1571+T1027 → G0099 0.705 > G0045 0.208 / T1105+T1027 → 두 그룹 0.337 동점 → 분류기 결합 필요
  • 지식 맵 활용: 예) G0139 전용 하위 군집 T1611·T1610·T1569·T1613 — 현장에서 T1610 탐지 시 나머지 3개 후속 예상. 그룹 식별 후엔 과거 기법·SW·악성도구로 최종 목표 예측

신뢰도 = 한 사고의 기법들이 같은 군집에 속한 비율(3개 중 3개 100%·2개 ≈66%·전부 다름 0%), 최대 군집 수 50·45·40·35·30·25로 실험 — 35까지 실용적. 50군집이면 군집당 ≈11 기법. Jaccard·Phi의 신뢰도 수치는 본문에 미기재(표 4). 그룹 식별 비교(표 5): TF-IDF top-15 37.36 / 53.45%, 의사결정트리 58.47 / 81.79%.

  • 그룹 식별(ID-K-G): 정확도 93.49% · 정밀도 97.87% · 재현율 93.49% · F1 94.9% — XGBoost 단독 대비 +6.3pp. ID-C-G는 86.37%(F1 85.9%)로 XGBoost(85.33%)와 근소
  • 유스케이스 1·3: T1591.004·T1199·T1204 탐지 → G1004 점수 2.439(차순위 G1001·G0027), 현재 단계 ‘초기 침투’ 판정. 추론된 후속 5개 중 T1098.003·T1136.003·T1578.002(내부 활동)는 다음 행위, T1593.003·T1584.002(인프라 확보)는 미탐지·미수행으로 해석
  • 유스케이스 2: 기법 5개 → 캠페인 C0017(후보 C0001·C0024), 단계 ‘내부 활동’, 후속 추론 T1059.003·T1016·T1005·T1071.001
  • 군집 품질: 7개 연결법 전수 비교(엔트로피↑·군집 크기 표준편차↓) → Jaccard=ward, Phi=average, 제안=ward 채택
  • 속도: 건당 4.01 ms, XGBoost 단독 0.93 ms(≈4×) — EDR/AV 맥락에서 허용 가능
왜 TTP만으론 안 되나: 기법 정보만으로 최고점을 받은 그룹이 평균 30개 동점(TF-IDF 가중만 적용해도 34개) → 30개 후보 제시는 방어자를 혼란시킴. 거리 보정 TR′=TR+ε/‖Vta−Vt‖(표 6)는 ε↑에 따라 동점은 줄지만 정확도도 동반 하락해 비실용. 임베딩 시각화에서 그룹끼리·기법끼리 뭉치는 얽힌 영역 확인 → 군집 기반은 통하나 거리 기반은 안 통함 → 비TTP 정보(실행파일 n-gram) + XGBoost 결합이 필수

⑥한계 · 향후

  • 분류기는 블랙박스(설명 부재) / GPT 등 언어모델 임베딩은 파인튜닝 비용 과다 → 설명 가능성 보강이 과제
  • 적대적 환경(로그 조작·명령 난독화로 TTP 식별 방해) 미검증, 학습에 없는 신규 기법·회피 전략·제로데이 미해결
  • 그룹 라벨 희소(ID-T 73건)·기법 ID 라벨링 신뢰도 문제, 클러스터 신뢰도는 표준 지표가 없어 자체 척도로 평가
