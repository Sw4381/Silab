암호화 트래픽에서 네트워크 플로우 기반 토폴로지 인식 비지도 침입탐지

Topology-aware unsupervised intrusion detection from network flows in encrypted traffic

이선우 · 정혜란 · 이태진(교신) 가천대 Computer Networks 292 (2027) 112940SCIE 2026.11.07 Accept 코드 공개: github.com/Sw4381/GNN_NIDS-Detector

핵심

페이로드 없이 플로우 메타데이터(패킷·바이트·포트)만으로 2분 단위 IP-pair 통신 그래프를 만들고, 정상 트래픽만 학습한 GNN 오토인코더의 엣지 재구성 오차로 이상을 탐지 — 증강(노이즈·마스킹)+대조학습(DGI)으로 강건성 확보

0.986일반 NIDS 4종 평균 ROC-AUC (1위)
0.936종단간 암호화 4조건 평균 ROC-AUC (1위)
0.911교차환경 전이 평균 (비교모델 0.415–0.609)
−3.0%재보정 없는 전이 시 상대 성능 저하
17.67ms2분 윈도우 1개 처리(CPU) · 122,906 flows/s

①문제의식

  • 암호화 확산: 웹 트래픽 95%+ HTTPS, TLS 1.3은 핸드셰이크 대부분(서버 인증서 포함)까지 암호화 → DPI 기반 NIDS 무력화
  • Q1 암호화 환경 탐지: 타이밍·크기 등 외형 정보만 관측 가능
  • Q2 대규모 처리: 대형망은 시간당 수백만 플로우 → 시간 집계·구조 추상화 필요
  • Q3 강건성: 실망 트래픽은 잡음·변화가 많고(concept drift), 지도학습은 라벨 의존·신규 공격 취약

②기존 연구와 차별점

계열대표한계
지도 MLRF·SVM·KNN대량 라벨 필요, 신규 공격·변화 대응 약함
비지도 AEKitNET, VAE플로우를 독립 처리 → 엔드포인트 간 구조 무시
지도 GNNE-GraphSAGE, TB-Graph라벨 의존, IP:Port 그래프는 규모 과대
비지도 GNNAnomal-E, GraphIDS2단계 학습(Anomal-E), IP 행위 특성 미반영
제안비지도 + 플로우 기반 + GNN + IP 행위(노드 토폴로지) 모델링을 모두 결합, 출처 편향 통제 평가

④평가 데이터 (6종 · 8조건)

  • 일반 NIDS: CIC-IDS2017(기업), NF-CSE-CIC-IDS2018-v3(클라우드), CIC-Edge-IIoTset(산업IoT), NF-UNSW-NB15-v3(테스트베드, 공격 4.6%)
  • 종단간 암호화: DoH 터널링 Setup 2(교차코퍼스)·Setup 3(동일출처), TQH-C2 — Sliver over TLS, Merlin over QUIC(HTTP/3)
  • 비교 6종: AE, VAE, KitNET, Anomal-E(IF/PCA), GraphIDS(NeurIPS'25)

③제안 방법

  • 그래프 구성: 2분 고정 윈도우, 노드=IP, 방향 엣지=(src,dst) 플로우 묶음 / 엣지 23차원(트래픽량 16·포트 6·플로우 수 1), 노드 4차원(밀도·out/in-degree·군집계수) — NetFlow·sFlow·IPFIX 공통 필드만 사용
  • Dual-stage AE: 노드←인접 엣지 평균 집계 → 엣지+양끝 노드 문맥 결합 인코딩(→16차원) → 잠재 엣지를 다시 노드로 집계해 디코딩, MSE 재구성
  • 강건 학습: 매 epoch 3개 증강 뷰 — 가우시안 노이즈(λ=0.2/0.5/0.7), 엣지 마스킹 5%, 노드 마스킹 3% (토폴로지는 보존)
  • 대조학습: 엣지 중심 DGI(정상 vs 섞은 그래프 판별), 손실 = 재구성 + 1.0×DGI
  • 설정: 전 데이터셋 동일 하이퍼파라미터, 100 epoch, CPU만 사용, 임계값은 Youden's J

평가 위생(Origin control): Setup 2는 정상=Jerabek, 악성=DoHBrw로 출처가 라벨과 일치 → 정상끼리만 비교해도 origin-AUC 0.942(1% 오탐 기준 타 출처 정상 20.3% 오탐). 즉 Setup 2의 0.98은 “환경 구분” 효과가 큼 → 암호화 DoH 성능 주장은 동일출처 Setup 3(0.797)에 근거
