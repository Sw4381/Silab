AI로 강화한 RMF: MITRE 기법 기반 위협 중심 보안통제 선정

Enhancing RMF with AI: Threat-centric control selection based on MITRE techniques

한태현 · 윤주한 · 이태진(교신) 가천대 · Finsecurity · 호서대 ICT Express (2025, Open Access CC BY)SCIE 2025.10.28 Accept · 10.30 Online DOI: 10.1016/j.icte.2025.10.011

핵심

자산의 C/I/A 정성 평가 대신 탐지된 MITRE 기법에서 출발 — 기법 간 관계를 metapath2vec 임베딩(+Jaccard·Phi)으로 정량화해 공격자의 다음 기법을 예측하고, ATT&CK↔SP 800-53 매핑표로 현재+예상 위협을 함께 막는 통제를 자동 추천 → RMF의 Categorize·Select·Monitor 단계를 위협 중심으로 전환

85%기법 클러스터 신뢰도 (45개 클러스터, metapath2vec)
+3.5%기법 완화율 향상 — 선제대응(pred) vs 탐지대응(init)
325,254KISA C-TAS 실제 침해사고 메타데이터 (대규모 셋)
3종관계 정량화: Jaccard · Phi · metapath2vec (MITRE v17.1)
7개↑통제 적용 시 선제대응 우위가 뚜렷해지는 지점

①문제의식

  • 전통 RMF의 한계: 자산을 C/I/A로 등급화해 통제를 고르는 정성·사후 방식 → 어떤 위협을 막는지 불명확, 전문가마다 결과가 다르고, 공격자 의도 미반영
  • 통제 과다: SP 800-53 통제가 방대해 특정 위협과의 관련성 판단이 어렵고, 가장 급한 대응이 지연
  • APT 잠복: 초기 침투 후 잠잠해지면 탐지 징후가 있어도 대응을 놓침 → 탐지된 기법에서 잠재 기법을 예측해 미리 통제해야
  • 지속 관리: 표준 범위가 넓고 유지비가 큼 → 자동화된 저비용 관리 모델 필요

④평가 데이터 · 설정

  • 데이터: KISA(C-TAS)에서 시기를 달리해 받은 실제 침해사고 메타데이터 2종 — 소규모 4,903건(그림엔 4,309로 표기) · 대규모 325,254건
  • 지식베이스: MITRE ATT&CK v17.1을 임베딩에 통합, 기법↔통제는 MITRE Engenuity NIST 800-53 매핑표
  • 클러스터링: 계층 클러스터링, 링크 방식은 엔트로피↑·표준편차↓ 기준 선택 — Jaccard·metapath2vec은 ward, Phi는 average (Fig.2)
  • 신뢰도 지표: 실제 사고에서 쓰인 기법 중 같은 클러스터에 속한 비율 (예: 8개 중 6개 → 75%)
  • 완화율 실험: 사고마다 초기에 쓰인 기법 3개 또는 5개를 '탐지됨'으로 가정 → 통제 1~10개 적용 시 완화된 기법 비율 비교

③제안 방법

  • 3단계 파이프라인: ① Jaccard·Phi로 기법 쌍 유사도 → ② metapath2vec으로 전 기법을 하나의 벡터 공간에 임베딩 → ③ 다음 기법 예측 + 대응 통제 추천 (Algorithm 1)
  • 임베딩: 기법을 공격 그룹과 연결한 메타패스(예: T1098–G0032–T1560)를 학습 — 같은 공격자가 쓴 기법끼리 가깝게. 목적함수 O(T)=log σ(Vt·Vt+1) + log σ(−Ve·Vt)(인접 기법 내적↑, 무관 기법 내적↓)
  • 잠재 기법(PT) 추론: 탐지 기법 n개와의 거리 합이 최소인 Tj를 선택 — PT ← argmin Σ u(M(Ti,Tj)+αj), M∈{Jaccard, Phi, Embedding}, α는 핵심 기법 가중치. 세 방법 중 최단 거리 채택
  • 클러스터 관리: 거리 기반 계층 클러스터링 → 같은 클러스터 = 함께 나타날 가능성이 큰 기법 집합. 임계값으로 클러스터 수 조절(Fig.3)
  • 통제 추천: 현재 탐지된 기법 + 예측 기법을 모두 고려해 매핑표에서 SP 800-53 통제 선택 → 사후 대응이 아닌 선제 대응
  • 기존 시스템 통합: RMF 7단계 중 Categorize·Select·Monitor만 강화하므로 기존 체계에 그대로 얹을 수 있음 (Table 1)

신뢰도는 최대 클러스터 수 60→30 구간 중 45개 이하에서의 값(Fig.4 판독, 근사). 완화율 행은 4,309건·탐지 3개 조건의 통제 10개 지점(Fig.5 판독, 근사). 본문 명시 수치: 신뢰도 약 85%, 완화율 개선 약 3.5%.

  • 예측 가능성: 45개 클러스터로 제한해도 약 85% 신뢰도 → 같은 수준의 확신으로 공격자 행동을 예측할 수 있음
  • 클러스터 해석 예: T1564.012·T1615·T1546.013은 겉보기엔 무관하지만 모두 Turla에서만 관측된 기법 → 하나를 탐지하면 나머지 대응이 쉬워짐. 클러스터를 조금 넓히면 여러 그룹이 공용하는 T1071.003·T1027.011까지 포함(확장성)
  • 선제 대응 효과: 통제를 많이 적용할수록 pred가 init보다 약 3.5% 더 많은 기법을 완화, 7개 이상에서 격차가 분명 — 작지만 선제 방어의 난이도를 감안하면 장기 지속 관리에서 의미 있는 이득
왜 임베딩인가: Jaccard·Phi는 기법 2개의 관계만 보므로 여러 기법이 동시에 얽힌 지능형 공격을 못 담음. 기법 관계는 발생 빈도가 주도하므로 어텐션(Transformer)보다 빈도 기반 비지도 임베딩(metapath2vec)이 적합 — MITRE TIE와 같은 문제의식이되, 계층 클러스터링으로 해석 폭을 넓히고 통제까지 직접 연결한 점이 차이

⑥한계 · 향후

  • 특정 환경(KISA)에서 수집한 데이터 → 편향·일반화 문제 미해결, 학습 데이터에 없는 공격 특성엔 결과 보장 불가
  • 완화율 개선 3.5%는 제한된 실험 조건에서의 값 — 탐지 기법 수·통제 수에 따라 초반(통제 ≤6개)엔 init과 역전되는 구간도 있음(Fig.5)
  • 통제 추천은 MITRE Engenuity 매핑표에 의존 — 매핑 갱신·조직별 통제 적용 비용은 미고려
